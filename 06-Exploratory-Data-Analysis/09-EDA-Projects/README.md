# 🔍 What Are EDA Projects?

An EDA project is a complete investigation of a dataset before applying Machine Learning or making analytical decisions.

Instead of asking:

> "Which chart should I create?"

you ask:

> "What can this dataset tell me?"

A complete EDA project combines multiple techniques:

```text
Inspection
   +
Cleaning
   +
Statistics
   +
Visualization
   +
Relationships
   +
Outliers
   +
Domain Questions
   ↓
Insights
```

---

# 🎯 Why Build EDA Projects?

Individual examples teach techniques.

Projects teach **problem-solving**.

Real-world datasets rarely arrive perfectly prepared.

You may encounter:

* Missing values
* Duplicate rows
* Incorrect data types
* Inconsistent categories
* Invalid values
* Outliers
* Skewed distributions
* High-cardinality features
* Class imbalance
* Unexpected relationships
* Data leakage
* Data-quality problems

EDA projects teach you how to deal with these situations systematically.

# 🧰 Reusable EDA Template

Every project can start with the same basic structure.

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns


def load_data(path):
    """Load the dataset."""

    return pd.read_csv(path)


def inspect_data(df):
    """Display basic dataset information."""

    print("Shape:", df.shape)
    print("\nColumns:")
    print(df.columns.tolist())

    print("\nData Types:")
    print(df.dtypes)

    print("\nMissing Values:")
    print(df.isna().sum())

    print("\nDuplicates:")
    print(df.duplicated().sum())


def numerical_summary(df):
    """Return descriptive statistics."""

    return df.describe(include="all")


def correlation_analysis(df):
    """Calculate numerical correlations."""

    numeric_df = df.select_dtypes(
        include="number"
    )

    return numeric_df.corr()


def main():
    """Run the basic EDA workflow."""

    df = load_data("data.csv")

    inspect_data(df)

    print("\nSummary:")
    print(numerical_summary(df))

    print("\nCorrelation:")
    print(correlation_analysis(df))


if __name__ == "__main__":
    main()
```

# 🕳️ Missing Value Analysis

Calculate missing values:

```python
missing = (
    df.isna()
    .sum()
    .sort_values(ascending=False)
)

print(missing)
```

Calculate percentages:

```python
missing_percentage = (
    df.isna()
    .mean()
    .sort_values(ascending=False)
    * 100
)

print(missing_percentage)
```

### Important

Do not automatically replace every missing value with the mean.

First understand:

```text
Why is the value missing?
How much data is missing?
Is missingness systematic?
Could missingness itself be informative?
```

# ♻️ Duplicate Analysis


# 🚨 Outlier Analysis

Use visual methods:

```python
sns.boxplot(
    data=df,
    y="feature"
)
```

Or IQR:

```python
q1 = df["feature"].quantile(0.25)
q3 = df["feature"].quantile(0.75)

iqr = q3 - q1

lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr

outliers = df[
    (df["feature"] < lower)
    | (df["feature"] > upper)
]

print(outliers)
```

### Important

Do not automatically delete outliers.

Determine whether they are:

```text
Valid Rare Event
        ↓
Keep

Data Entry Error
        ↓
Correct

Measurement Error
        ↓
Investigate

Extreme but Valid
        ↓
Consider Transform / Robust Method
```

# 🧰 Reusable EDA Code

Reusable functions reduce repeated code.

```python
def missing_value_report(df):
    """Return missing-value statistics."""

    report = pd.DataFrame({
        "missing_count": df.isna().sum(),
        "missing_percentage": (
            df.isna().mean() * 100
        )
    })

    return report.sort_values(
        "missing_percentage",
        ascending=False
    )


def duplicate_report(df):
    """Return duplicate count."""

    return {
        "duplicate_rows": int(
            df.duplicated().sum()
        )
    }


def numerical_columns(df):
    """Return numerical column names."""

    return df.select_dtypes(
        include="number"
    ).columns.tolist()


def categorical_columns(df):
    """Return categorical column names."""

    return df.select_dtypes(
        include=["object", "category"]
    ).columns.tolist()


def correlation_matrix(df):
    """Return numerical correlation matrix."""

    return (
        df
        .select_dtypes(include="number")
        .corr()
    )
```

# 🚀 End-to-End EDA Template

```python
"""
End-to-End Exploratory Data Analysis Template
----------------------------------------------
Use this structure as the foundation for
real-world EDA projects.
"""

from pathlib import Path

import matplotlib.pyplot as plt
import pandas as pd
import seaborn as sns


def load_dataset(path):
    """Load a CSV dataset."""

    path = Path(path)

    if not path.exists():
        raise FileNotFoundError(
            f"Dataset not found: {path}"
        )

    return pd.read_csv(path)


def inspect_dataset(df):
    """Print basic dataset information."""

    print("=" * 60)
    print("DATASET INSPECTION")
    print("=" * 60)

    print(f"Shape: {df.shape}")

    print("\nColumns:")
    print(df.columns.tolist())

    print("\nData Types:")
    print(df.dtypes)

    print("\nMissing Values:")
    print(df.isna().sum())

    print("\nDuplicate Rows:")
    print(df.duplicated().sum())

    print("\nSummary Statistics:")
    print(df.describe(include="all"))


def create_missing_report(df):
    """Create a missing-value report."""

    report = pd.DataFrame({
        "missing_count": df.isna().sum(),
        "missing_percentage": (
            df.isna().mean() * 100
        )
    })

    return report.sort_values(
        "missing_percentage",
        ascending=False
    )


def visualize_numeric_columns(df):
    """Create histograms for numerical columns."""

    numeric_columns = df.select_dtypes(
        include="number"
    ).columns

    for column in numeric_columns:

        plt.figure(figsize=(8, 5))

        sns.histplot(
            data=df,
            x=column,
            kde=True
        )

        plt.title(
            f"Distribution of {column}"
        )

        plt.tight_layout()
        plt.show()


def visualize_categorical_columns(df):
    """Create count plots for categorical columns."""

    categorical_columns = df.select_dtypes(
        include=["object", "category"]
    ).columns

    for column in categorical_columns:

        if df[column].nunique() > 15:
            continue

        plt.figure(figsize=(8, 5))

        sns.countplot(
            data=df,
            x=column
        )

        plt.title(
            f"Distribution of {column}"
        )

        plt.xticks(rotation=45)

        plt.tight_layout()
        plt.show()


def correlation_heatmap(df):
    """Create a correlation heatmap."""

    numeric_df = df.select_dtypes(
        include="number"
    )

    if numeric_df.shape[1] < 2:
        return

    correlation = numeric_df.corr()

    plt.figure(figsize=(10, 7))

    sns.heatmap(
        correlation,
        annot=True,
        fmt=".2f"
    )

    plt.title(
        "Correlation Heatmap"
    )

    plt.tight_layout()
    plt.show()


def main():
    """Run the complete EDA workflow."""

    sns.set_theme()

    df = load_dataset(
        "data/dataset.csv"
    )

    inspect_dataset(df)

    print("\nMissing Value Report:")
    print(create_missing_report(df))

    visualize_numeric_columns(df)

    visualize_categorical_columns(df)

    correlation_heatmap(df)


if __name__ == "__main__":
    main()
```

# 🤖 EDA for Machine Learning

EDA should help answer:

```text
What is the target?
        ↓

        ↓
Which features have missing values?
        ↓
Which features contain outliers?
        ↓
Which features are highly skewed?
        ↓
Which features are correlated?
        ↓
Are there redundant features?
        ↓
Is the target imbalanced?
        ↓

```

However, EDA does **not** mean using the entire dataset indiscriminately before modeling.

For supervised ML, be careful with information that comes from the test set.

---

# 🔐 Avoiding Data Leakage

A common mistake is allowing future or test information to influence analysis decisions.

For example:

```text
Entire Dataset
     ↓
Calculate Scaling Parameters
     ↓
Train/Test Split
```

This can leak information.

Prefer:

```text
Dataset
   ↓
Train/Test Split
   ↓
Fit Preprocessing on Train
   ↓
Transform Train
   ↓
Transform Test
```

The same principle applies to:

* Imputation
* Scaling
* Feature selection
* Target encoding
* Transformation parameters
* Model-driven feature selection

EDA for understanding the dataset can be broad, but **modeling decisions must respect the train/test boundary**.

# ⚠️ Common Mistakes

## ❌ 1. Creating charts without questions

Visualization should support analysis.

---

## ❌ 2. Automatically deleting outliers

Investigate first.

---

## ❌ 3. Automatically filling missing values

Understand why values are missing.

---

## ❌ 4. Ignoring data types

A date stored as text is not equivalent to a datetime feature.

---

## ❌ 5. Treating correlation as causation

Association does not establish cause.

---

## ❌ 6. Ignoring class imbalance

Accuracy can hide poor minority-class performance.

---

## ❌ 7. Data leakage

Never allow test information to influence training-time preprocessing.

---

## ❌ 8. Generating hundreds of meaningless charts

More visualizations do not necessarily mean better EDA.

---

## ❌ 9. Not documenting decisions

A professional EDA project should explain:

```text
What was found?
Why was something changed?
What assumptions were made?
What limitations remain?
```

---

# ✅ Best Practices

### 1. Start with a problem statement

Know what you are trying to understand.

### 2. Understand the dataset

Read the data dictionary and understand each feature.

### 3. Inspect before cleaning

Never modify data before understanding its structure.

### 4. Keep transformations reproducible

Write preprocessing steps in code.

### 5. Use appropriate statistics

Mean, median, IQR, standard deviation, and correlations answer different questions.

### 6. Visualize strategically

Every visualization should provide information.

### 7. Investigate anomalies

Rare observations may contain important information.

### 8. Document insights

A chart without interpretation is incomplete analysis.

### 9. Consider domain knowledge

Statistical unusualness does not always mean business unusualness.

### 10. Connect EDA to ML

EDA should ultimately help guide:

```text
Feature Engineering
Feature Selection
Model Choice
Evaluation Strategy
```
