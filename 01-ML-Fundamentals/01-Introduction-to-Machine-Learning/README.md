# Introduction to Machine Learning

 > A beginner-friendly introduction to the fundamentals, terminology, workflow, and real-world applications of Machine Learning.

 ## 📌 Overview

 Machine Learning (ML) is a branch of Artificial Intelligence that enables computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every possible situation.

 Instead of writing rules for every scenario, we provide a machine learning algorithm with data and allow it to learn a useful pattern or relationship.

 ### Traditional Programming

```
        Rules
          +
        Data
          ↓
       Program
          ↓
        Output
```

 ### Machine Learning

```
        Data
          +
       Output
          ↓
    ML Algorithm
          ↓
        Model
          ↓
    New Prediction
```

 ## 🧠 What is Machine Learning?

 Machine Learning is a field of computing in which algorithms learn patterns from data and use those patterns to make predictions, classifications, or decisions.

 ### Simple Example

 Suppose we have data about houses:

 | Area (sq ft) | Bedrooms | Price |
| --- | --- | --- |
| 1000 | 2 | ₹40 Lakh |
| 1500 | 3 | ₹60 Lakh |
| 2000 | 3 | ₹80 Lakh |
| 2500 | 4 | ₹100 Lakh |

 A machine learning algorithm can learn the relationship between:

```
House Features → House Price
```

 After training, we can provide a new house:

```
Area = 1800 sq ft
Bedrooms = 3
```

 and the model can estimate its price.

 ## 🔑 Important Terminology

 ### Dataset

 A collection of data used for analysis or machine learning.

 ### Feature

 An input variable used by a model to make a prediction.

 Example:

```
Area
Bedrooms
Location
Age
```

 ### Label / Target

 The value that we want the model to predict.

 Example:

```
House Price
```

 ### Model

 A mathematical representation learned from training data.

 ### Training

 The process of allowing a machine learning algorithm to learn patterns from data.

 ### Prediction

 The output generated by a trained model for new data.

 ### Algorithm

 A mathematical procedure used to learn patterns from data.

 Examples:

 - Linear Regression
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine
- K-Means

 ## 🤖 Types of Machine Learning

 Machine Learning is commonly divided into:

 ### 1\. Supervised Learning

 The model learns from labeled data.

 Examples:

 - House price prediction
- Spam detection
- Disease classification
- Customer churn prediction

 ### 2\. Unsupervised Learning

 The model discovers patterns in data without predefined labels.

 Examples:

 - Customer segmentation
- Clustering
- Dimensionality reduction
- Anomaly detection

 ### 3\. Semi-Supervised Learning

 Uses a combination of labeled and unlabeled data.

 ### 4\. Reinforcement Learning

 An agent learns by interacting with an environment and receiving rewards or penalties.

 ## 🆚 Traditional Programming vs Machine Learning

 | Traditional Programming | Machine Learning |
| --- | --- |
| Rules are explicitly written | Patterns are learned from data |
| Programmer defines logic | Algorithm learns logic |
| Input + Rules → Output | Input + Output → Model |
| Suitable for deterministic rules | Suitable for pattern-based problems |
