# Notebooks

 This folder contains Jupyter Notebook examples for **Introduction to Machine Learning**.

 ## Notebooks

 - `01-machine-learning-introduction.ipynb` — Basic Machine Learning concepts
- `02-features-and-labels.ipynb` — Features and labels
- `03-train-test-split.ipynb` — Training and testing data
- `04-first-machine-learning-model.ipynb` — First ML model
- `05-predictions-and-evaluation.ipynb` — Predictions and model evaluation
- `06-complete-ml-workflow.ipynb` — Complete beginner ML workflow

 ## Run Notebooks

 From the repository root:

```
jupyter notebook
```

 Or:

```
jupyter lab
```

 ## Requirements

 Install the required libraries:

```
pip install numpy pandas matplotlib scikit-learn jupyter
```

 ## Learning Flow

```
Data

  ↓

```
